# 🕹️ NEON STATION // Arcade OS

👉 **[▶️ JUGAR AHORA ONLINE (GitHub Pages)](https://ezequielzero.github.io/neon-station-arcade/)** 👈

Portal web arcade con **3 juegos clásicos en 2D** desarrollados en HTML5 Canvas, CSS3 moderno (estilo Cyber-Neon) y JavaScript Vanilla a 60 FPS con efectos de sonido sintetizados mediante **Web Audio API**.

## 🎮 Juegos incluidos

1. **🧱 Tetris (`Cyber Blocks`)**
   - Generador justo *7-bag*, proyección de pieza fantasma (*Ghost Piece*), vista previa de siguiente pieza y sistema de reserva (`C` / `Shift`).
   - Puntuación por niveles, caída rápida (`Espacio`) y efectos de partículas al completar líneas.

2. **🐍 Snake (`Neon Viper`)**
   - Manzanas neón y **Estrellas Doradas de Bonus** con temporizador.
   - Modo configurable con **muros letales** o **bordes abiertos** (teletransporte) y turbo sprint (`Espacio`).

3. **🏎️ Turbo 2D (`Highway Drift`)**
   - Autopista de 4 carriles a alta velocidad con distintos tipos de tráfico, monedas de energía y reparación de escudos.
   - Sistema de **Nitro Boost** recargable (`Espacio` / `Shift`) y bonificaciones por adelantamientos al límite (*Near Miss*).

## 🚀 Cómo jugar

Abre el archivo `index.html` directamente en cualquier navegador moderno.
